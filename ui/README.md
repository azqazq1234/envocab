# Envocab UI

Run `npm run dev` in this directory, then open http://localhost:3000.

The development server listens on `0.0.0.0:3000`. Devices on the same network can access it at `http://<chobitmac-lan-ip>:3000`. Backend requests are proxied through the frontend.

See the [root README](../README.md) for installation, backend and database configuration, and verification commands.
